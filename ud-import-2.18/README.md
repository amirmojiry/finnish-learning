# Universal Dependencies 2.18 import

این پوشه موقت برای آپلود فایل‌های `.conllu` مربوط به چهار treebank فنلاندی Universal Dependencies نسخه 2.18 ساخته شده است.

فایل‌های train، dev و test مربوط به این treebankها را در همین پوشه قرار دهید:

- Finnish-TDT
- Finnish-FTB
- Finnish-OOD
- Finnish-PUD

پس از استخراج و اعتبارسنجی داده‌های موردنیاز، فایل‌های خام این پوشه حذف خواهند شد.
