# آموزش فنلاندی

**[باز کردن نسخه آنلاین برنامه](https://amirmojiry.github.io/finnish-learning/)**

[English README](README.md)

یک برنامه وب سبک و مناسب موبایل برای یادگیری و تمرین صورت‌های واژگانی پرتکرار فنلاندی با ترجمه فارسی.

## امکانات فعلی

- ۴۰۰ صورت واژگانی پرتکرار در زبان نوشتاری فنلاندی با ترجمه فارسی
- رتبه منبع، تعداد وقوع و درصد وقوع دقیق بر اساس Parole
- جست‌وجو در واژه‌نامه و مرتب‌سازی الفبایی یا بسامدی
- فیلترهای نوع واژه فقط برای دسته‌هایی که در واژه‌نامه فعلی حداقل یک مدخل دارند
- نوع غالب واژه و تحلیل صرفی بر اساس Universal Dependencies
- مثال‌های واقعی UD با ترجمهٔ فارسیِ محلی برای مثال‌های نمایش‌داده‌شده و پخش صوت جمله‌های فنلاندی، از جمله مثال مخصوص هر مقدار صرفی
- صفحه اختصاصی هر واژه با معنی، شکل پایه، مثال‌های دوزبانه، پخش صوت جداگانه برای هر مثال، تلفظ و تحلیل پیکره‌ای
- بخش مستقل «تمرین واژه» که مرور هوشمند در آن بین ترجمه، جای‌خالی چهارگزینه‌ای و پاسخ تایپی می‌چرخد
- مسیر ۱۴۰ درسی شامل ۴۰ درس A1.1، ۴۰ درس A1.2، ۴۰ درس A1.3 و ۲۰ درس قابل‌بازیِ دو بخش اول A2.1 در مجموع ۱۴ بخش با موضوعات خرید، رفت‌وآمد، زندگی روزمره، سلامت، تعامل اجتماعی، خانه و محله، تحصیل و کار و رویدادهای اخیر، با دسترسی همیشگی برای مشاهدهٔ A1.1 و A1.2 و A1.3 و A2.1، امکان پرش به درس اول بخش‌های پیاده‌سازی‌شده مانند مسیر A1.1، حفظ پیشرفت بین سطوح، تولید پاسخ فارسی‌به‌فنلاندی، شنیدن و دیکتهٔ فنلاندی، تمرین ساختاری جمله و تمرین صرف با فرم‌های بازبینی‌شده
- تمرین هدفمند هر بخش که با سه پاسخ درست متوالی یا جبران اشتباه در پایان همان درس، ضعف را برطرف می‌کند و سابقهٔ دقت تجمیعی را همچنان نگه می‌دارد
- تاریخچهٔ زمانی محدود و محلی برای پاسخ‌های دوره با ترتیب پایدار، شناسهٔ جلسه، زمان پاسخ، تمایز تمرین تولیدی از تشخیصی و کیفیت پاسخ تایپی برای تصمیم‌های آینده دربارهٔ mastery
- ماتریس اجرایی ۴۰ درسی A1.2، سیلابس اجرایی ۴۰ درسی A1.3 و طرح ۴۰ درسی A2.1 که ۲۰ درس در دو بخش اول آن اجرایی شده‌اند و دو بخش دیگر هنوز در حد طرح‌اند
- حالت بدون حواس‌پرتی داخل درس با پنهان‌شدن ناوبری عمومی، نوار پیشرفت فشرده و نمایش feedback پاسخ داخل viewport
- صف مرور فاصله‌دار در بخش «تمرین واژه»، با تقدم واژه‌های موعددار و سقف روزانه ده واژه جدید
- فهرست قابل کلیک واژه‌های مرورشده همراه با دقت پاسخ و وضعیت یادگیری
- نمایش وضعیت مرور هر واژه در صفحه جزئیات واژه‌نامه
- برآورد پوشش توکن‌های مرورشده و تثبیت‌شده بر اساس درصد بسامد Parole
- ذخیره محلی زمان مرور بعدی، تعداد پاسخ‌ها، لغزش‌ها و وضعیت تسلط هر واژه شروع‌شده
- ناوبری چهارقسمتی «دوره، واژه‌نامه، تمرین واژه، تنظیمات»؛ بخش‌های قدیمی خانه و پروفایل حذف شده‌اند
- پذیرش جایگزینی‌های a/ä و o/ö در پاسخ تایپی به‌صورت «نزدیک و قابل قبول»، همراه با نمایش املای استاندارد فنلاندی
- قابل کلیک بودن واژه‌های موجود در واژه‌نامه داخل مثال‌ها
- بخش تنظیمات علاوه بر حالت روشن و تیره، مشخص می‌کند پخش فنلاندی با voice صریح مرورگر انجام می‌شود یا با مسیریابی زبانی fi-FI مرورگر/دستگاه و راهنمای TTS را نشان می‌دهد
- ذخیره محلی پیشرفت دوره، تم، زمان‌بندی مرور، تاریخچه پاسخ‌ها و وضعیت تسلط

درصد پوشش، برآوردی از سهم صورت‌های واژگانی مرورشده در توکن‌های پیکره نوشتاری Parole است. این عدد به معنی سنجش کامل فهم زبان فنلاندی یا توانایی ارتباطی کاربر نیست.

## مالکیت منابع داده

مسئولیت منابع داده در پروژه از هم جدا نگه داشته می‌شود:

- **Parole/Kotus/Kielipankki** منبع رتبه بسامد، تعداد وقوع، صورت واژه و درصد وقوع است.
- **Universal Dependencies** منبع نوع غالب UPOS، شکل‌های پایه مشاهده‌شده در پیکره، ویژگی‌های صرفی، وابستگی‌ها، توزیع treebank و مثال‌های پیکره‌ای است.
- **داده آموزشی بازبینی‌شده** منبع ترجمه فارسی، نوع واژه جایگزین، شکل پایه آموزشی و دو جفت مثال فنلاندی و فارسی است.

رتبه‌بندی از [فهرست بسامد صورت‌های واژگانی زبان نوشتاری فنلاندی](https://www.kielipankki.fi/lexical-conceptual-resources/parole-taajuuslista/) گرفته شده است. این فهرست بر پیکره نوشتاری Parole با حدود ۱۷ میلیون توکن استوار است. چون این منبع فهرست صورت‌های واژه است، صورت‌های صرف‌شده، مخفف‌ها و عددها را نیز شامل می‌شود. رتبه‌های مساوی منبع در `frequency_rank` حفظ می‌شوند، اما `position` و `rank` در خود اپ یکتا و متوالی هستند.

## مسیرهای مهم داده

- `data/common-words.json`: واژه‌نامه تولیدشده‌ای که اپ مصرف می‌کند
- `data/course/a1.1-section-1.json` تا `data/course/a1.1-section-4.json`: manifestهای بازبینی‌شدهٔ مسیر کامل A1.1
- `data/course/a1.2-curriculum.json`: قرارداد بازبینی‌شدهٔ ۴۰ درسی A1.2 که ورودی تحلیل شکاف واژگان است
- `data/course/a1.3-curriculum.json`: قرارداد بازبینی‌شدهٔ ۴۰ درسی A1.3 که مدل برنامه‌ریزی‌شدهٔ زیرسطح‌های A1 را کامل می‌کند
- `data/course/a1.2-vocabulary-gap.json`: گزارش تولیدشدهٔ پوشش واژگانی و شکاف منبع A1.2
- `data/parole_frek_3.txt`: فایل اصلی Latin-1 فهرست بسامد Parole
- `data/vocabulary-details/`: بسته‌های بازبینی‌شدهٔ بازه‌های واژگان متکی به منبع، از جمله موقعیت‌های ۳۰۱ تا ۴۰۰
- `data/ud/`: فایل‌های تولیدشده تحلیل کامل و خلاصه UD
- `ud-import-2.18/`: فایل‌های CoNLL-U ورودی pipeline تحلیل UD
- `scripts/build-vocabulary.mjs`: سازنده قابل‌بازتولید واژه‌نامه
- `scripts/analyze-a1-2-vocabulary.mjs`: تحلیلگر قطعی و قابل‌بازتولید شکاف واژگان A1.2
- `tools/ud-import/`: ابزارهای استخراج UD و ساخت خلاصه مخصوص مرورگر

فایل‌های JSON تولیدشده در `data/ud/` و فایل `data/course/a1.2-vocabulary-gap.json` نباید دستی ویرایش شوند.

## بازتولید گزارش شکاف واژگان A1.2

این گزارش اهداف واژگانی `data/course/a1.2-curriculum.json` را با واژه‌نامهٔ فعلی در `data/common-words.json` و فایل اصلی Parole که در metadata واژه‌نامه معرفی شده مقایسه می‌کند.

```bash
node scripts/analyze-a1-2-vocabulary.mjs
node scripts/analyze-a1-2-vocabulary.mjs --check
```

پس از تغییر اهداف A1.2، واژه‌نامهٔ فعلی یا منبع Parole فرمان اول را اجرا کنید. حالت `--check` نگهبان بازتولیدپذیری در تست‌هاست و اگر گزارش commitشده قدیمی باشد با خطا متوقف می‌شود.

## افزودن یک بازه واژه

برای افزودن بازه‌ای مانند جایگاه‌های ۲۰۱ تا ۳۰۰:

۱. یک بسته بازبینی‌شده مانند `data/vocabulary-details/201-300.json` با schema توضیح‌داده‌شده در همان پوشه اضافه کنید.
۲. سازنده واژه‌نامه را اجرا کنید؛ رتبه، تعداد، صورت واژه و درصد مستقیماً از فایل اصلی Parole خوانده می‌شوند.
۳. خروجی‌های UD را دوباره تولید کنید.
۴. تعدادهای نمایشی، cache keyها، متادیتای انتشار و بلوک وضعیت هر دو README را همگام کنید.
۵. نسخه MINOR را افزایش دهید، `CHANGELOG.md` را به‌روزرسانی کنید و تمام تست‌ها را اجرا کنید.

```bash
npm run build:vocabulary
python3 tools/ud-import/extract_ud.py
python3 tools/ud-import/enrich_multiword_tokens.py
python3 tools/ud-import/enrich_ui_examples.py
python3 tools/ud-import/build_ui_summary.py
python3 tools/ud-import/connect_ui.py
npm run sync
npm test
```

workflow مربوط به UD در GitHub همین تولید و اعتبارسنجی را هنگام تغییر ورودی‌ها به‌صورت خودکار انجام می‌دهد.

```bash
npm run sync
npm test
npm run test:js

```

فرمان‌های نسخه‌گذاری:

```bash

npm run version:minor
npm run version:major
```

فایل `VERSION` مرجع اصلی نسخه برنامه است. فرمان‌های نسخه‌گذاری، `package.json`، cache key فایل‌های محلی، متادیتای انتشار، قالب Changelog و بلوک وضعیت هر دو README را همگام می‌کنند.

## کیفیت و انتشار

برای pull requestها و شاخه‌های غیر از `main`، CI اجرا می‌شود. مجموعه تست‌ها سازگاری نسخه، بازتولیدپذیری واژه‌نامه، انطباق دقیق با Parole، schema واژه‌ها، پوشش UD، رگرسیون `ovat → AUX`، مثال‌های مخصوص ویژگی‌های صرفی، فیلتر پویای نوع واژه، زمان‌بندی مرور فاصله‌دار، محاسبه پوشش بسامدی، ترتیب واژه‌های مرورشده، وضعیت هر واژه، مالکیت «تمرین واژه» و تنظیمات در ناوبری، ترتیب scriptها، همگامی مستندات، انگلیسی‌بودن کامنت‌های کد و اتصال صحیح دروازه انتشار را بررسی می‌کند.

انتشار GitHub Pages به موفقیت کامل job اعتبارسنجی وابسته است و نسخه‌ای با تست ناموفق یا فایل تولیدشده قدیمی منتشر نمی‌شود.
