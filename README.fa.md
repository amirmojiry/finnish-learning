# آموزش فنلاندی

**[باز کردن نسخه آنلاین برنامه](https://amirmojiry.github.io/finnish-learning/)**

[English README](README.md)

یک برنامه وب سبک و مناسب موبایل برای یادگیری و تمرین واژگان فنلاندی با ترجمه فارسی.

## امکانات فعلی

- ۱۰۰ صورت واژگانی پرتکرار در زبان نوشتاری فنلاندی
- نمایش رتبه، تعداد وقوع و درصد وقوع در پیکره
- واژه‌نامه با جست‌وجو، مرتب‌سازی الفبایی یا بسامدی و فیلتر نوع واژه
- صفحه اختصاصی هر واژه با معنی، نوع، شکل پایه، مثال‌ها و تلفظ
- سه تمرین ترجمه، جای‌خالی چهارگزینه‌ای و جای‌خالی تایپی
- تمرین اختصاصی برای یک واژه مشخص
- راهنماهای مرحله‌ای و صفحه‌کلید کوچک حروف
- دو مثال فنلاندی با ترجمه فارسی برای هر مدخل
- قابل کلیک بودن واژه‌های موجود در واژه‌نامه داخل مثال‌ها
- حالت روشن و تیره
- ذخیره امتیاز، نوع تمرین و تم در مرورگر

داده‌های اصلی در فایل [`data/common-words.json`](data/common-words.json) قرار دارند.

## منبع واژگان

رتبه‌بندی جدید از **فهرست بسامد صورت‌های واژگانی زبان نوشتاری فنلاندی** گرفته شده است که مؤسسه زبان‌های فنلاند، Kotus، از طریق Kielipankki منتشر کرده است. این فهرست بر پیکره نوشتاری Parole با حدود ۱۷ میلیون توکن استوار است.

چون این منبع فهرست «صورت‌های واژه» است، فقط شکل پایه را شامل نمی‌شود و صورت‌های صرف‌شده‌ای مانند `suomen`، `vuoden`، `olivat` و `suomessa` نیز در آن وجود دارند. مدخل‌هایی مانند مخفف `mm` و عدد `1` هم مستقیماً از همان پیکره آمده‌اند.

هر یک از ۲۰۰ مدخل شامل موارد زیر است:

- رتبه بسامد
- تعداد وقوع در پیکره
- درصد وقوع
- صورت واژه فنلاندی
- ترجمه فارسی
- نوع واژه به فارسی و انگلیسی
- شکل پایه یا `lemma`
- دو مثال فنلاندی با ترجمه فارسی

منبع: [Kotus / Kielipankki — Frequency List of Written Finnish Word Forms](https://www.kielipankki.fi/lexical-conceptual-resources/parole-taajuuslista/)

## اجرای محلی

```bash
python3 -m http.server 8000
```

سپس آدرس `http://localhost:8000` را باز کنید.

## بازسازی داده‌های واژگان

اطلاعات بسامد و جزئیات آموزشی به‌صورت جداگانه نگهداری و در فایل اصلی ادغام می‌شوند:

```bash
node scripts/build-parole-vocabulary.mjs
```
