# پذیرش بخش دوم A1.3: خانه، محله و مشکلات روزمره

نسخهٔ 1.46.0؛ [ایشوی ۱۷۲](https://github.com/amirmojiry/finnish-learning/issues/172) زیرمجموعهٔ [ایشوی مادر ۱۰۱](https://github.com/amirmojiry/finnish-learning/issues/101).

هر ده درس اهداف ارتباطی، واژگانی و گرامری روشن دارند. بخش ۳۰۵ فعالیت دارد؛ ۴۱ مورد هدف فاقد پاسخ مثبت و چهار معرفی تکراری رفع شده‌اند. هر ۵۹ صورت/عبارت تازه بازیابی مثبت بعدی و نه مفهوم گرامری محدود مرور بعدی دارند. پیش‌نیازها و هویت‌های دقیق با نه بخش قبلی مقایسه می‌شوند؛ این شمارش، تعداد واژک/معنیِ بازبینی‌شده یا رویداد یادگیری کاربر نیست.

کاربردهای محدود شامل on/ovat، جای وسایل با pöydällä/kaapissa/lattialla، مصدر پس از Pitää، منفی‌سازی با ei، درخواست Tarvitsen huoltoa، درخواست مؤدبانه، پرسش خدمات محله و ساعت کار هستند. صورت مفرد و جمع یا حالت مکانی اشتباه پذیرفته نمی‌شود. Täällä saa odottaa و Täällä ei saa tupakoida الگوهای محدود اعلان‌اند. Ongelma ei ole vielä korjattu عبارت آماده می‌ماند؛ این جمله مدرک آموزش مولد مجهول یا ماضی نقلی نیست. برنامهٔ مادر و گراف پیش‌نیازها تغییر نمی‌کنند.

Voitteko auttaa minua? در درس پنجم و Milloin se on auki? در درس هفتم، پیش از مرور آموزش داده می‌شوند. Osoite on … فقط الگوی تشخیص معنی است و از کاربر تایپ سه‌نقطه خواسته نمی‌شود. جملهٔ صریح Osoite on Koulukatu 5. برای تمرین تولید آموزش داده می‌شود؛ نشانی دیگری به‌عنوان همان پاسخ پذیرفته نمی‌شود.

یک متن ساعت کار با دو پرسش در درس هفتم افزوده می‌شود. دو متن قبلی هر کدام دو پرسش با پاسخ روشن در درس نهم دارند. نوشتن چهار جملهٔ درخواست تعمیر از جمله‌های آموزش‌داده‌شده استفاده می‌کند. درس‌های نهم و دهم هدف تازه معرفی نمی‌کنند. پاسخ‌های تولیدی و جایگزین‌های زمان اجرا برای تولید و دیکته با سیاست دقیق صرفی بررسی می‌شوند؛ ارفاق حروف فنلاندی حفظ می‌شود.

تمام رکوردهای قبلی بدون تغییر حفظ شده‌اند؛ فقط یک جملهٔ نشانی مشخص و یک متن ساعت کار افزوده شده‌اند. شناسه‌ها، نگاشت‌های اصلی، هدف‌های تولید و شنیدن، پانزده هدف آزمون و شرط ۸۰٪ حفظ شده‌اند. آزمون ۲۵ فعالیت دارد: ۲۰ پاسخ درست قبول و ۱۹ پاسخ رد است. پیشرفت ذخیره‌شده بازنویسی نمی‌شود. تعداد فعالیت درس‌ها ۲۱ تا ۳۷ است؛ تصمیم R3 دربارهٔ تعداد درس‌ها باز می‌ماند.

بازتولید: `npm run section:a13:s2:write`؛ کنترل: `npm run section:a13:s2:check`؛ گزارش: `npm run section:a13:s2:report`. [گزارش انگلیسی](A13-SECTION2-ACCEPTANCE.md) و [دادهٔ پذیرش](../data/course/a1.3-section-2-acceptance.json) شواهد را نشان می‌دهند. تست‌ها حذف پاسخ و مرور، آموزش پس از سنجش، پاسخ گرامری اشتباه، تولید سه‌نقطه، تغییر داده‌های اصلی و آزمون را تشخیص می‌دهند.

این‌ها فرصت‌های تمرین راهنمایی‌شده‌اند، نه گواهی تولید مستقل یا CEFR/YKI. قدم بعد هر ده درس بخش سوم A1.3 است. هویت‌های P2، مرور P5، تعداد درس‌های R3 و پذیرش نهایی زیر ایشوی مادر باز هستند؛ بخش سوم قابل‌بازی A2.1 به این زیرساخت‌ها وابسته است. [نقشهٔ راه](ROADMAP.fa.md) مرجع ادامه است.
