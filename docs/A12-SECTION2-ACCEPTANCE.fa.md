# پذیرش بخش دوم A1.2: رفت‌وآمد و مسیریابی

نسخهٔ 1.42.0، ۱۴ اکتبر ۲۰۲۶؛ [ایشوی ۱۶۴](https://github.com/amirmojiry/finnish-learning/issues/164)، زیرمجموعهٔ [ایشوی مادر ۱۰۱](https://github.com/amirmojiry/finnish-learning/issues/101).

هر ده درس اهداف واژگانی، گرامری و ارتباطی مشخص دارند. بخش ۳۰۹ فعالیت دارد و ۵۴ مورد هدف بدون پاسخ مثبت در محتوای قبلی رفع شده‌اند. تمام ۸۰ صورت/عبارت تازه در درس بعدی بازیابی مثبت دارند. هویت‌ها با چهار بخش A1.1 و بخش اول A1.2 مقایسه می‌شوند تا محتوای قبلی دوباره «جدید» نامیده نشود. درس نهم و آزمون پایانی هدف تازه معرفی نمی‌کنند. طول درس‌ها بر اساس هدف متفاوت است؛ درس هفتم ۴۴ فعالیت و ۱۶ هدف تازه دارد.

پنج مفهوم محدود شامل پرسش، حالت‌های مکانی، امر، قیدهای بسامد/زمان و مقدار مرور می‌شوند. امر فقط در نمونه‌های مفرد آموزش‌داده‌شده سنجیده می‌شود. صورت‌های مکان و وسیلهٔ سفر صریح هستند و صرف کامل را آموزش نمی‌دهند. عبارت‌های بلیت راهنمایی‌شده می‌مانند. پاسخ‌هایی مثل `Olen asemalle`، `Kaksi lippu` و `ennen kymmenen` به‌جای صورت گرامری درست پذیرفته نمی‌شوند. این سنجش مدرک تولید مستقل یا سطح CEFR/YKI نیست.

سه عبارت و یک متن برنامهٔ حرکت افزوده شده‌اند؛ تمام رکوردهای قبلی بدون تغییر حفظ شده‌اند. عبارت‌های تازه پیش از نخستین سنجش آموزش داده می‌شوند، حتی وقتی پاسخ از جای خالیِ تمرین صرف ساخته می‌شود. برنامهٔ حرکت دو پرسش با یک پاسخ درست دارد. نوشتن سه جملهٔ سفر در درس نهم فقط از جمله‌های آموزش‌داده‌شده استفاده می‌کند؛ گفت‌وگو و دو پرسش خواندن سفرِ قبلی هم حفظ شده‌اند.

شناسه‌ها، هدف‌های تولید و شنیدن، ارجاع‌های برنامهٔ درسی و پانزده هدف اصلی آزمون حفظ شده‌اند. آزمون ۲۴ فعالیت و همان شرط ۸۰٪ دارد؛ پیشرفت ذخیره‌شده پاک یا بازنویسی نمی‌شود. تست‌ها حذف هدف، حذف مرور، معرفی تکراری، آموزش پس از سنجش، پاسخ غلط گرامری و تغییر شرط آزمون را تشخیص می‌دهند.

بازتولید: `npm run section:a12:s2:write`؛ کنترل: `npm run section:a12:s2:check`؛ گزارش: `npm run section:a12:s2:report`. [گزارش انگلیسی تولیدشده](A12-SECTION2-ACCEPTANCE.md) جزئیات هر درس را نشان می‌دهد.

گام بعد بخش سوم A1.2 است. هویت‌های P2، مرور P5، تعداد درس‌های R3 و پذیرش نهایی زیر ایشوی مادر باز می‌مانند؛ بخش سوم قابل‌بازی A2.1 هنوز به آن زیرساخت‌ها وابسته است. مرجع برنامهٔ ادامه [نقشهٔ راه](ROADMAP.fa.md) است.
