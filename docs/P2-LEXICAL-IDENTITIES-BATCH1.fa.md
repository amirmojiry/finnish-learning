# P2 — اولین دستهٔ تأیید هویت واژگانی

[گزارش خودکار](P2-IDENTITY-BATCH1-REPORT.md) · [توضیح انگلیسی](P2-LEXICAL-IDENTITIES-BATCH1.md) · [ایشوی #182](https://github.com/amirmojiry/finnish-learning/issues/182) · [ایشوی مادر #101](https://github.com/amirmojiry/finnish-learning/issues/101)

در این مرحله **۴۰ صورت واژگانی مشخص** (۱۷ صورت ضمیری و ۲۳ صورت اسمی) در کنار **۷ مورد تأییدشدهٔ قبلی** قرار گرفته‌اند: مجموعاً **۴۷ صورت از ۱۲۶۴ رکورد**. از این ۴۰ صورت، ۳۸ مورد در درس‌های موجود استفاده شده‌اند؛ «hänen» و «heidän» فعلاً تنها در واژه‌نامه هستند و نباید تدریس‌شده محسوب شوند.

**منظور از تأیید:** تشخیص دقیق یک صورت نوشتاری، واژهٔ پایه، معنای محدود به بافت و حالت صرفی آن است. این کار به معنی یادگیری، تسلط، قبولی در امتحان، همسان‌شدن سوابق مرور فاصله‌دار یا تسلط بر تمام صرف‌های یک واژه نیست.

## گروه‌هایی که مرور شدند

- ضمایر شخصی: «minä / minun / minulle»، «hän / hänen»، «me / meidän»، «te» و «he / heidän». در «te» شمار دستوری جمع است، هرچند در خطاب مؤدبانه برای یک نفر هم استفاده می‌شود.
- ضمایر اشاره: «tämä / tässä / tästä / tähän» و «se / siinä / siitä / siihen»، با تمایز حالت‌های مکان/مبدأ/مقصد.
- ضمیر پرسشی «mikä».
- زمان: «aikaa» (پارتیتیو) و «aikana» (اسیو) در معنای *زمان*. صورت «ajan» به دلیل هم‌نوشت بودن با فعل «رانندگی می‌کنم» فعلاً تأیید نشده است.
- خانه: «koti» و «kotiin» در معنای خانه/به خانه؛ شهر: «kaupunki / kaupungin».
- نام، شماره، تلفن، نشانی، پیام، مدرسه، فروشگاه، داروخانه، ایستگاه، اتوبوس، بلیت، آشپزخانه، اتاق نشیمن، اتاق خواب، رسید، کارت و آب («vesi»).

معنی‌های بررسی‌شده از کاربرد و ترجمهٔ همین درس‌ها گرفته شده‌اند. برای نمونه، «lippu» در معنای *بلیت* بررسی شده است، نه تمام معانی احتمالی آن.

## مواردی که عمداً تأیید نشدند

- «aika» به‌تنهایی هم اسم «زمان» است و هم کاربرد قیدی دارد؛ «ajan» نیز می‌تواند اسم «وقت/زمان» یا فعل «رانندگی می‌کنم» باشد. بنابراین هر دو فعلاً تأیید نشده‌اند؛ فقط «aikaa / aikana» در معنای اسمی ثبت شده‌اند.
- «kotona» یک حالت مکانی تثبیت‌شده و تاریخی است و نباید صرف آزاد «koti» فرض شود.
- «voi»، «pitää» و «tuli» چندمعنایی‌اند و نیازمند بازبینی مستقل معنای هر کاربرد هستند.
- عبارت‌های چندواژه‌ای هنوز بررسی هویت معنایی نشده‌اند.

رتبه، شمارش و درصد پیکرهٔ **Parole** تغییر نکرده است. داده‌های اصلی واژه‌نامه، شناسه‌های درس‌ها، نمرات قبلی، و تاریخچهٔ مرور Word Practice دست‌نخورده‌اند. تست‌ها باید اتصال اشتباه معنی، حالت صرفی نامعتبر، ساختن شناسهٔ بدون شاهد و انتقال نادرست تسلط را رد کنند.

منابع دستور زبان انگلیسی: [Aalto University](https://openlearning.aalto.fi/mod/book/tool/print/index.php?id=7549)، [ضمایر شخصی فنلاندی](https://jkorpela.fi/finnish/Personal_pronouns.html)، [ضمیرهای اشاره](https://jkorpela.fi/finnish/Demonstrative_pronouns_t%C3%A4m%C3%A4%2C_1.html)، [صورت‌های aika](https://uusikielemme.fi/finnish-vocabulary/interesting-words/aikaa-ajaksi-aikana-ajassa-using-aika-in-sentences) و [حالت مکانی تثبیت‌شدهٔ kotona](https://jkorpela.fi/finnish/Essive.html).

اجرای کنترل‌ها: `npm run lexical:identity:check` و `npm run p2:identity:check`؛ بازتولید گزارش: `npm run p2:identity:write`. قبل از بخش سوم A2.1 هنوز کارهای زیرساختی ایشوی مادر بازند.
