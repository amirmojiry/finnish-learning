# پذیرش بخش اول A1.2: خرید و خدمات

[گزارش قابل‌بازتولید](A12-SECTION1-ACCEPTANCE.md) · [مرکز مستندات](README.md) · [نقشهٔ راه](ROADMAP.fa.md)

هر ده درس، هدف ارتباطی، صورت‌های واژگانی و نمونه‌های گرامریِ مشخص دارد. مجموع فعالیت‌ها ۲۶۵ است؛ هر ۷۱ صورت/عبارت تازه پاسخ مثبت و بازیابی در درس بعدی دارد. مرور و آزمون پایانی واژهٔ تازه معرفی نمی‌کنند. مرجع اعداد به‌تنهایی سنجش محسوب نمی‌شود.

شش مفهوم محدود، مرور بعدی دارند: مقدار و قیمت، درخواست مؤدبانهٔ آماده، روش پرداخت با کارت/نقدی، منفی «Tämä ei toimi.» و مرور پرسش‌ها و جمله‌های «olla». «Haluaisin» صرف کامل شرطی را آموزش نمی‌دهد؛ «kortilla/käteisellä» جدول کامل حالت‌های مکانی نیستند. پاسخ گرامری باید صورت درستِ مشخص یا معادل بدون نشانهٔ آوایی آن باشد؛ «ei toimii» و «korttia» به‌جای «kortilla» پذیرفته نمی‌شوند.

وضعیت مرور و پیش‌نیازها از چهار بخش A1.1 می‌آید. هویت واژه و معنای آن با این گزارش ادغام نمی‌شود و شمار صورت‌ها شمار واژه‌های مستقل تأییدشده نیست. دادهٔ قبلیِ آیتم‌ها، شناسه‌ها، هدف‌های اصلی شنیدن/تولید، پانزده هدف آزمون و شرط قبولی ۸۰٪ حفظ شده‌اند. این گزارش دربارهٔ فرصت‌های تمرینِ نوشته‌شده است و مدرک تسلط فرد یا سطح CEFR/YKI نیست.

با `npm run section:a12:s1:write` گزارش ساخته و با `npm run section:a12:s1:check` بررسی می‌شود. قدم بعد، تکمیل کل ده درس بخش دوم A1.2 است؛ کارهای گستردهٔ هویت، مرور و پذیرش نهایی زیر ایشوی مادر ۱۰۱ باز می‌مانند.
