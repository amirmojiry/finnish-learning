# قرارداد مشترک هویت واژگان P2 — نسخهٔ 1.75.0

[ایشوی #237](https://github.com/amirmojiry/finnish-learning/issues/237) · [ایشوی اصلی #101](https://github.com/amirmojiry/finnish-learning/issues/101) · [English](P2-SHARED-IDENTITY-CONTRACT.md)

## زیرساخت پیاده‌سازی‌شده

مرجع اصلی، فایل تولیدی `data/course/lexical-identity-sidecar.json` است. تمام صورت‌های واژه و عبارت‌ها شناسهٔ پایدار `form_id` یا `expression_id` دارند. اکنون شناسهٔ موضوعِ رسمی بخش آموزشی و فهرست درس‌هایی که به‌صراحت یک مورد را «مرور» معرفی کرده‌اند نیز ثبت می‌شود. فیلد قدیمی `review_lessons` صرفاً حضور در درس‌های بعدی را نشان می‌دهد، نه پاسخ نمره‌دار یا یادگیری واقعی.

فایل `data/course/p2-cross-app-identity.json` این داده‌ها را به‌صورت بازتولیدپذیر به **۱۲۶۴ شناسهٔ پایدار، ۱۱۷۸ ارجاع یکتای درس و تمام ۴۲۵ واژهٔ فرهنگ لغت/تمرین واژگان** وصل می‌کند. اتصال به Word Practice فقط بر اساس *صورت نوشتاری دقیق* است؛ تاریخچه یا امتیاز بین شکل‌های صرفی منتقل نمی‌شود. رتبه و بسامد اصلی Parole و ساختار `data/common-words.json` تغییر نکرده‌اند.

## مرز هویت معنایی

- **۷۰ مورد** هویت سراسریِ ریشه، معنا و ویژگی صرفیِ بازبینی‌شده دارند.
- **۱۱۹۴ مورد** هنوز از نظر معنایی تأیید نشده‌اند و شناسهٔ ریشه/معنای آن‌ها عمداً `null` است. تولید داده به معنای تأیید زبان‌شناختی نیست.
- **۱۵ کاربرد وابسته به بافت** از پنج صورت مبهم، فقط در همان شناسهٔ دقیق بخش/مورد پذیرفته می‌شوند. برای نمونه `aika`، `ajan`، `voi`، `pitää` و `tuli` معنای سراسریِ حدسی نمی‌گیرند.
- شناسه‌های موضوع به بخش‌های رسمی برنامهٔ درسی اشاره دارند؛ برچسب‌های آزادِ آیتم، مرجع رسمی گرامر محسوب نمی‌شوند. مرجع پیش‌نیازها `data/course/master-curriculum.json` است.
- ذکر یک واژه در درس، تمرین نمره‌دار و تسلط واقعی زبان‌آموز مفاهیم جداگانه‌اند.

## اتصال در برنامه

فایل کامل داده برای ممیزی نگهداری می‌شود؛ مرورگر فقط نمایهٔ فشردهٔ حدود **۱۷۴ کیلوبایتی** `data/course/p2-cross-app-runtime.json` را دریافت می‌کند. هر دو فایل با یک سازنده تولید و بازبینی می‌شوند.

ماژول `p2-shared-identity.js` برای Course، Dictionary و Word Practice شناسهٔ یکسان و قابل‌ردیابی را برمی‌گرداند. تنها Course می‌تواند معنای تأییدشدهٔ وابسته به *همان کاربرد مشخص* را نمایش دهد. تمام کلیدهای ذخیرهٔ پیشرفت Course و SRS و زمان‌بندی مرور بدون تغییر باقی مانده‌اند. در صورت بارگذاری‌نشدن نمایه، عملکرد قبلی ادامه پیدا می‌کند.

برای بازتولید: `npm run lexical:identity:write`، سپس `npm run p2:context:write`، `npm run p2:cross-app:write`، `npm run sync` و `npm test`.

**نتیجه:** پیوند فنی شناسه‌ها تکمیل می‌شود، اما این ادعای بازبینی زبان‌شناختی همهٔ ۱۱۹۴ مورد نیست؛ آن تصمیم‌ها نیازمند شواهد و بازبینی مستقل‌اند.
