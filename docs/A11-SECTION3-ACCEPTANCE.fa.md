# پذیرش بخش سوم A1.1

[گزارش قابل‌بازتولید انگلیسی](A11-SECTION3-ACCEPTANCE.md) · [راهنمای مستندات](README.md) · [نقشهٔ راه](ROADMAP.fa.md)

در نسخهٔ 1.39.0 هر ده درسِ روز، زمان و کارهای روزمره هدف‌های ارتباطی، واژگانی و گرامری روشن دارد. بخش ۲۸۲ فعالیت دارد. هر ۸۰ صورت/عبارتِ معرفی‌شده فرصت پاسخ درست و بازیابی در درس بعدی دارد؛ پنج مفهوم گرامری محدود نیز دوباره سنجیده می‌شوند. این تعداد شمار واژه‌ها یا معنی‌های مستقلِ بررسی‌شده نیست و تسلط زبان‌آموز را اثبات نمی‌کند.

نسخهٔ قبلی ۴۸ مورد هدفِ اعلام‌شده بدون پاسخ درست در همان درس داشت. اکنون شکاف پاسخ درست و برچسب تکراریِ «جدید» در گزارش بخش سوم صفر است. پیش‌نیاز گرامر و وضعیت مرور، دو بخش پیشین را هم در نظر می‌گیرد؛ «mitä» و «en» دوباره جدید نامیده نمی‌شوند.

| --- | ---: | --- |
| ۱ | ۱۵ | امروز، فردا، دیروز و الگوی آشنای on |
| ۲ | ۱۸ | تمام هفت روز هفته |
| ۳ | ۲۰ | ساعت‌های کامل یک تا پنج |
| ۴ | ۲۲ | صبح، روز، عصر و شب |
| ۵ | ۴۰ | صورت‌های آشنای اول‌شخص و جمله‌های برنامهٔ روزانه |
| ۶ | ۲۷ | سؤال از مخاطب و جمله‌های کامل آشنا |

| ۱۰ | ۳۷ | هدف‌های اصلی آزمون و مرور هر پنج فعل منفی |

منفی‌سازی با پنج جفتِ صریح انجام می‌شود: `syön → syö`، `juon → juo`، `nukun → nuku`، `opiskelen → opiskele` و `työskentelen → työskentele`. بعد از `En` صورت منفی لازم است؛ `En syön` یا `En opiskelen` پاسخ درست نیست. خطای قبلی که این صورت‌ها را به‌دلیل شباهت نوشتاری قبول می‌کرد رفع شده است. تبدیل منفی و پاسخ‌های نوشتاری گرامریِ مشخص‌شده، فقط صورت درستِ نرمال‌شده یا تفاوتِ تایپ ä/ö را می‌پذیرند؛ ارفاق معمولِ غلط تایپی برای تمرین‌های واژگانیِ فاقد این سیاست باقی می‌ماند.

تمام روزهای هفته، ساعت‌های کامل یک تا پنج و چهار صورت زمانی سنجش و بازیابی بعدی دارند. جمله‌های لازم برای برنامهٔ روزانه پیش‌تر در درس‌های ۵ و ۶ آموزش داده می‌شوند؛ درس‌های ۹ و ۱۰ هدف جدید ندارند. عبارت‌های مرجعِ دارای «…» و جفت‌های نمایشیِ دارای پیکان، با شناخت معنی سنجیده می‌شوند و هرگز عیناً برای تایپ درخواست نمی‌شوند.

شناسه‌ها، دادهٔ قبلی همهٔ واژه‌ها، نمره‌های ذخیره‌شده، پنج جفت منفی و هر پانزده هدف اصلی آزمون حفظ شده‌اند. شنیدن، املا و تولید از فارسی همچنان وجود دارند؛ گزینه‌های شنیداری از محدودهٔ اصلاح‌شدهٔ درس ساخته می‌شوند. حالت‌های زمانی و «kotiin» نمونه‌های محدود و کامل‌اند؛ صرف آزاد حالت‌ها، تمام اشخاص فعل، زمان گذشته، مکالمهٔ مستقل یا مدرک CEFR/YKI ادعا نمی‌شود. «eilen» در درس اول هدف واژگانی است؛ جملهٔ نمونهٔ گذشته، شاهد سنجش زمان گذشته نیست.

کنترل: `npm run section:a11:s3:check`؛ بازتولید: `npm run section:a11:s3:write`. گزارش [JSON](../data/course/a1.1-section-3-acceptance.json) معرفی و بازیابی هر هدف را ثبت می‌کند. کنترل بخش سوم و دو بخش قبلی در `npm test` اجرا می‌شوند.
