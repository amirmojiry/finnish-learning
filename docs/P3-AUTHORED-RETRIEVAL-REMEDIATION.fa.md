# P3: مرور نمره‌دار واقعی بدون تغییر آرشیو درس‌ها — نسخهٔ 1.76.0

[ایشوی #239](https://github.com/amirmojiry/finnish-learning/issues/239) · [ایشوی اصلی #101](https://github.com/amirmojiry/finnish-learning/issues/101) · [English](P3-AUTHORED-RETRIEVAL-REMEDIATION.md)

## چه چیزی اصلاح می‌شود؟

ممیزی ۱۴۰ درس موجود نشان داده بود که **۶۲ مورد از ۹۳۱ معرفی صورت واژه/عبارت، در درس‌های بعدی هیچ بازیابی نمره‌داری ندارند**. این موارد در بخش‌های قدیمی A1.1 و A1.2 متمرکز هستند. سازندهٔ `scripts/build-p3-reviewed-retrievals.cjs` برای هر کدام یک فرصت مرور نمره‌دار، پس از حداقل یک درس فاصله، قرار می‌دهد؛ تمرین‌ها فقط از واژه‌ها، جمله‌های فنلاندی و ترجمه‌های فارسیِ از قبل موجود در منابع محتواییِ برنامه استفاده می‌کنند.

برای هر درس جدیدِ مقصد، حداکثر **دو تمرین** اضافه می‌شود و این کار فقط برای درس‌های غیربخشی (غیر checkpoint) و بدون زمان‌بندی نشسته انجام می‌گیرد. آرایهٔ تاریخی `activities`، نام و شناسهٔ درس‌ها، نسخه‌های پیشینِ ویرایش آموزشی، نمره‌های ذخیره‌شده و SRS تغییر نمی‌کنند. فقط شروع جدید درس، نسخهٔ تکمیلی `p3` را می‌بیند؛ تکمیل قبلی یک درس نیز لغو نمی‌شود.

اگر یک جملهٔ فنلاندی معتبرِ از پیش تألیف‌شده، همراه ترجمهٔ فارسی و شامل خودِ صورت واژه موجود باشد، تمرین جای‌خالی می‌تواند آن را در بافت قابل‌مشاهده بررسی کند؛ در غیر این صورت بازیابی نوشتاریِ صورت دقیق واژه صورت می‌گیرد. **تکرار واژه یا ترجمه‌نویسی بدون نمایش جملهٔ متفاوت، شاهد تعمیم به بافت جدید محسوب نمی‌شود.** منشأ داده برای هر تمرین ثبت شده و در تست‌ها کنترل می‌شود.

## بازتولید و آزمون

`npm run p3:reviews:write` برای ساخت محتوای قطعی، `npm run p3:reviews:check` برای تطبیق فایل‌ها، `npm run p3:reviews:json` برای گزارش انتخاب‌ها و `npm test` برای آزمون کامل استفاده می‌شود. داده‌های P2 و اتصال Course/Dictionary/Word Practice پس از تغییرات بازسازی می‌شوند.

## کار محتوایی باقی‌مانده

موضوع دوم P3 هنوز جداگانه باز است: ممیزی اولیه **۸۳۸ مورد بدون بازیابی نمره‌دار در یک جملهٔ واقعاً متفاوت فنلاندی** را نشان می‌داد. تکرار همان مثال، یا اضافه‌کردن سؤال فارسی به فنلاندی، این معیار را کامل نمی‌کند. موارد بدون شاهد معتبر باید به تألیف و بررسی زبانی سپرده شوند. نسبت پیشنهادی ۲ واژهٔ پرتکرار + ۲ موضوعی + ۱ عبارت و ۳ تا ۵ مرور نیز سهمیهٔ اجباری برای درس‌های تاریخی نیست.

بنابراین تکمیل این بخشِ «مرور نمره‌دار» به معنای تکمیل همهٔ معیارهای جامع P3 یا اثبات تسلط واقعی زبان‌آموز نیست.
