# پذیرش آموزشی بخش اول A1.1

[گزارش قابل‌بازتولید انگلیسی](A11-SECTION1-ACCEPTANCE.md) · [گزارش ماشین‌خوان](../data/course/a1.1-section-1-acceptance.json) · [نقشهٔ راه](ROADMAP.fa.md)

این گزارش فرصت‌های آموزشی و سنجشِ تألیف‌شده را ثبت می‌کند؛ نمره یا تسلط زبان‌آموز، توانایی مکالمهٔ مستقل یا گواهی CEFR/YKI نیست.

در نسخهٔ 1.37.0 هر ده درس بخش بررسی شده‌اند. مجموع ۲۳۳ فعالیت، ۴۹ صورت و عبارت معرفی‌شده با مرور بعدی و پنج مفهوم گرامری با مرور بعدی وجود دارد. هیچ هدف اعلام‌شده‌ای بدون پاسخ درست قابل‌سنجش نمانده و هیچ صورت قبلی دوباره «جدید» معرفی نشده است. این ۴۹ مورد، ۴۹ واژهٔ پایه یا معنیِ بررسی‌شده نیستند؛ هویت واژگانی P2 همچنان کار جداگانه‌ای است.

- درس‌های ۱ و ۶ سلام و ادب را به‌صورت عبارت‌های ثابت آموزش می‌دهند؛ هدف گرامری ساختگی ندارند.
- درس ۲ صورت‌های محدود معرفی با «olen» و «olet» را می‌سنجد؛ درس‌های بعد این مفهوم را با «on» در معرفی شیء مرور می‌کنند.
- درس ۳ عبارت آمادهٔ حال‌واحوال را می‌آموزد؛ صرف آزاد فعل «kuulua» ادعا نمی‌شود.
- درس‌های ۴ و ۷ الگوهای محدود «Ei ole» و «En ymmärrä» را تمرین می‌کنند؛ صرف همهٔ اشخاص یا منفی‌سازی آزاد جمله‌ها آموزش داده نشده است.
- درس‌های ۵ و ۸ پرسش دربارهٔ شخص/شیء و کاربردهای پایهٔ ضمیرها را می‌سنجند؛ صورت‌های مکانی در مثال‌ها، آموزش کامل حالت‌های اسمی محسوب نمی‌شوند.
- درس‌های ۹ و ۱۰ فقط مرور هستند. عبارت‌های ترکیبیِ مرور قبلاً در درس‌های معرفی و درخواست تکرار آموزش داده می‌شوند. آزمون پایانی ۱۵ هدف اصلی را نگه می‌دارد و با مرورهای تکمیلی ۲۴ فعالیت دارد؛ واژهٔ جدید ندارد.

تعداد فعالیت‌ها با پوشش واقعی هدف‌ها تعیین شده است، نه برای رسیدن به سهمیهٔ ثابت. شناسهٔ درس‌ها، تمرین‌های شنیدن/دیکته و تولید پاسخ و نمره‌های قدیمی حفظ می‌شوند. معرفی مجددِ عبارت آشنا با برچسب مرور نمایش داده می‌شود.

برای بررسی دوباره:

```bash
npm run section:a11:check
npm run section:a11:report
```

گزارش ماشین‌خوان، برای هر هدف واژگانی و گرامری، محل معرفی و درس‌های مرور بعدی را نشان می‌دهد. این نتیجه فقط پذیرش همین بخش است؛ بخش‌های دیگر و گیت‌های ایشوی مادر هنوز باید جداگانه تکمیل شوند.
