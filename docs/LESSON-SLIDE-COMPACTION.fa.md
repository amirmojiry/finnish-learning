# گروه‌بندی تمرین‌ها و کاهش طول نمایشی درس‌ها

[سند انگلیسی](LESSON-SLIDE-COMPACTION.md) · [ایشوی #189](https://github.com/amirmojiry/finnish-learning/issues/189) · [سیاست R2](R2-LESSON-SLIDE-BUDGET.md)

در ۱۴۰ درس اجرایی، ۵۵ درس بیش از ۳۰ فعالیت تألیف‌شده و چهار درس بیش از ۴۰ فعالیت دارند. بیشترین تعداد ۶۲ فعالیت است. این آمار **محتوای ثبت‌شده** است، نه مدت واقعی مطالعه یا خستگی ثبت‌شدهٔ کاربران.

در درس‌های طولانی، فعالیت‌های **پشت‌سرهم و هم‌نوع** در گروه‌های حداکثر چهار‌تایی روی یک صفحه نشان داده می‌شوند: آموزش واژگان همراه با پخش صوت دستی، تطبیق واژه و معنی با فهرست انتخاب قابل استفاده با صفحه‌کلید، پاسخ تایپی فنلاندی و تولید جمله با راهنما. **هیچ سؤال یا هدف آموزشی حذف نمی‌شود.** هر پاسخ همچنان جداگانه ارزیابی و در سوابق پاسخ نخست، نمره و مرور هدف ثبت می‌شود؛ پاسخ‌های نادرست نیز به‌صورت مستقل قابل جبران‌اند.

ترتیب اصلی فعالیت‌ها، شناسه‌های ۱۴۰ درس، checkpointها، پرسش‌های شنیداری، گرامر و سوابق یادگیری حفظ می‌شوند. تعداد **اسلایدهای اولیه** برای هر درس حداکثر ۳۰ است؛ مرور جبرانی پس از پاسخ اشتباه می‌تواند صفحات بیشتری ایجاد کند. برای کوتاه‌سازی واقعیِ محتوای آموزشی و رسیدن به حدود ۱۲ تا ۲۰ اسلاید، بررسی تحریریه‌ای و تقسیم احتمالی درس‌ها در کارهای بعدی ایشو #189 پیگیری می‌شود.

## ممیزی بازتولیدپذیر

- `npm run lesson:slides:report`: جدول تعداد فعالیت اصلی، اسلاید نمایشی و پاسخ‌های مستقل.
- `npm run lesson:slides:json`: گزارش قابل پردازش.
- `npm run lesson:slides:check`: بررسی سقف ۳۰ و حفظ ترتیب تمام فعالیت‌ها.

این اعداد حاصل ممیزی محتوا هستند؛ داده‌ای دربارهٔ زمان یادگیری، رهاکردن درس یا گواهی CEFR/YKI نداریم. رابط موبایل، صفحه‌کلید و صفحه‌خوان باید در ریویوی مرورگر نیز بررسی شوند.
