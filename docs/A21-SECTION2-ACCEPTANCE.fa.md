# پذیرش محتوایی بخش دوم A2.1: پزشک و خدمات عمومی

[English](A21-SECTION2-ACCEPTANCE.md) · [فهرست مستندات](README.md) · [ایشوی #180](https://github.com/amirmojiry/finnish-learning/issues/180)

این بسته، **۱۰ درس موجود** دربارهٔ گرفتن و تغییر وقت پزشک، گزارش نشانه‌ها، درخواست توضیح از کارکنان، پرسش از داروخانه، یافتن باجهٔ خدمات، تکمیل فرم و درخواست مدرک را پوشش می‌دهد. داده‌های اولیهٔ ۸۵ مدخل، شناسه‌های درس و هدف‌های اصلی دست‌نخورده مانده‌اند.

- اهداف **ارتباطی، واژگانی و دستوری** به‌صورت مستقل و با پیش‌نیازهای کامل ۱۲ بخش A1 و بخش اول A2.1 ثبت شده‌اند.
- برای هر صورت واژه یا عبارت تازه، پاسخ صحیحِ قابل‌ارزیابی و **مرور مثبت در درس بعدی** پیش‌بینی شده است. تعدادهای دقیق و موارد خطا در [خروجی ماشینی ممیزی](../data/course/a2.1-section-2-acceptance.json) قرار دارند.
- زمان گذشته برای گزارش شروع نشانه‌ها، منفی اول‌شخص، بیان مقدار با حالت پارتیتیو، پرسش‌های مؤدبانه، ضرورت، صرف حال و حاکمیت حالت در پرسیدن دربارهٔ دارو به‌صورت **الگوهای محدود** تمرین می‌شوند، نه صرف آزاد همهٔ صورت‌ها.
- هر دو متن خواندن درس نهم **دو سؤال مستقل** دارند؛ در درس هشتم و نهم، نوشتن هدایت‌شده با **چهار عبارت کاملِ ازپیش‌آموخته‌شده** قرار دارد.
- درس نهم مرور است. آزمون درس دهم با همان **۱۵ هدف** و حدنصاب **۸۰ درصد** باقی مانده است.
- مثال‌های پزشکی فقط برای یادگیری زبان‌اند؛ هیچ توصیهٔ بالینی شخصی یا مقدار مصرف دارو ارائه نمی‌کنند.

**مرز اعتبار:** وجود تمرین و پاسخ صحیح در داده‌ها نشان‌دهندهٔ یادگیری مستقل، توانایی آزاد در زبان یا گواهی CEFR/YKI نیست. کارهای P2/P5/R3 و پیش‌نیازهای بخش سوم همچنان باز هستند.

برای کنترل از `npm run section:a21:s2:check` و برای بازتولید از `npm run section:a21:s2:write` استفاده کنید.
