# پذیرش آموزشی A2.1 بخش اول: سفر و گذشته

[English](A21-SECTION1-ACCEPTANCE.md) · [فهرست مستندات](README.md) · [ایشوی #178](https://github.com/amirmojiry/finnish-learning/issues/178)

- هر ده درس موجود پوشش داده می‌شوند: سفر، حرکت، بلیت، اقامت، مشکلات سفر و روایت گذشته.
- برای هر معرفی جدید، پاسخ صحیح قابل ارزیابی و مرور بعدی پیش‌بینی شده است. [گزارش ماشینی](../data/course/a2.1-section-1-acceptance.json) و `npm run section:a21:s1:report` شواهد دقیق را نشان می‌دهند.
- آموزش گرامر گذشتهٔ ساده، حالت مفعول، پارتیتیو جمع، مکان و مقصد، حاکمیت حالت، -maan و ترتیب اتفاق‌ها محدود به مثال‌های تدریس‌شده است، نه صرف آزاد.
- در درس‌های هشتم و نهم نوشتن هدایت‌شدهٔ چهار جمله وجود دارد؛ دو متن اصلی درس نهم هرکدام دو سؤال فهم مطلب دارند.
- درس‌های نهم و دهم واژه و عبارت تازه معرفی نمی‌کنند. شناسه‌ها و اهداف آزمون نهایی (۱۵ هدف و حدنصاب ۸۰٪) محفوظ‌اند.
- این بررسی به معنای تسلط مستقل، گواهی رسمی CEFR/YKI یا تکمیل مراحل P2/P5/R3 نیست.

دستورها: `npm run section:a21:s1:check` و `npm run section:a21:s1:write`.
